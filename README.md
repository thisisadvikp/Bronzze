# Bronzze
A new tab page extension

HOW to SET UP:
1. Click on the puzzle icon (Extensions) -> Click "Manage Extensions"
2. Click "Dev mode"
3. Click "Load unpacked" and select the file that you have downloaded
4. When you open a new tab, it will ask you if you want to keep the extension or change it back; click "Keep it"

 YOU HAVE SUCCESSFULLY INSTALLED BRONZZE NEW TAB EXTENSION!!!
